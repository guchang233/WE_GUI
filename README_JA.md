# 概要
WorldEditを複雑なコマンドの構文を覚えることなくより簡単に操作できるようにGUIパネルと ([Litematica](https://modrinth.com/mod/litematica)の図面配置のような) 選択範囲の3Dでの描画を提供します。英語・中国語・日本語がサポートされています。

# 機能
---
📂 WEコマンドカテゴリー

 使用可能な全てのコマンドを機能別に分類して、簡単にクリックで使えるようにする計画です。(現在も最適化中)
 
---
👁 3Dプレビュー描画
  
 `//copy`の後、どこで`//paste`するとどこに配置されるかが確認できます。

---
📋 クイックホイールメニュー

 カスタマイズ可能・使用可能なコマンドを追加できる機能です。(近日公開)
